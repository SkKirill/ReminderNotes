**Цель**
> Создать мобильное Android-приложение для ведения текстовых заметок с возможностью помечать важные записи и получать напоминания. Приложение должно помогать пользователю хранить личные заметки, возвращаться к ним в нужное время и постепенно расширяться от простого списка до полноценного приложения с архитектурой MVVM и уведомлениями.

**Описание приложения**
> Приложение позволяет пользователю создавать, редактировать и удалять текстовые заметки. Каждая заметка содержит заголовок, основной текст и дополнительные атрибуты (важность, выполненность, напоминание). Заметки отображаются в виде списка и могут быть открыты для детального просмотра и редактирования. В рамках сквозной лабораторной работы приложение поэтапно дополняется локальным хранением данных, загрузкой данных с сервера, использованием Room, архитектуры MVVM, Dependency Injection, а также уведомлениями и голосовым вводом.

---

**1.0** – Базовый функционал
*Функциональные требования*
- Реализовать главный экран со списком заметок.
- Реализовать CRUD-операции:
- - добавление новой заметки;
- - редактирование существующей заметки;
- - удаление заметки.
- Каждая заметка должна содержать:
- - заголовок заметки;
- - текст заметки.
- Отображение списка заметок - **RecyclerView (XML)** 
- Для отображения одного элемента списка - **CardView (XML)** 
- Ввод данных реализовать через диалоговое окно.
- Данные можно хранить только в памяти приложения (без сохранения между перезапусками).

---

**2.0** – Фрагменты и локальное сохранение
*Функциональные требования*
- Разделить приложение минимум на два фрагмента:
- - экран со списком заметок;
- - экран детального просмотра и редактирования заметки.
- Реализовать навигацию между фрагментами.
- При создании заметки должен генерироваться уникальный id (UUID).
- Передавать данные между фрагментами через Bundle или SafeArgs (если используется Navigation Component)
- Реализовать локальное сохранение заметок между перезапусками приложения в SharedPreferences.
- Добавить возможность отмечать заметку как “важную”:
- - чекбокс, переключатель или иконка (boolean);
- - статус важности сохранять в SharedPreferences.
- Использовать Snackbar для подтверждения действий:
- - при добавлении заметки;
- - при удалении заметки;
- - при сохранении изменений.

---

**3.0** – Работа с сервером и асинхронность
*Функциональные требования*
- Получать список заметок с сервера в формате JSON
- Использовать Retrofit и Gson для облегчения работы с сервером.
- Отображать загруженные заметки в общем списке.
- Реализовать автоматическое обновление данных одним из вариантов:
- - Раз в минуту через: Kotlin Coroutines + delay
- - Обновление по кнопке «Обновить»
- - Или через SwipeRefreshLayout
- Обрабатывать корректные и некорректные HTTP-ответы: при ошибке отображать Snackbar.
- Каждая заметка должна иметь уникальный id (UUID или строка).
- При повторной загрузке данные обновляются по id.
- Сетевые запросы не должны выполняться на главном потоке.
- Загруженные заметки объединять с локальными, обновляя их по id и сохраняя локальные статусы.
- Локальные статусы (важность и выполненность) должны сохраняться при обновлении данных с сервера.
- Возможность отмечать заметки как выполненные (локальное хранение в SharedPreferences).

---

**4.0** – Room, MVVM и Dependency Injection
*Функциональные требования*
- Использовать Room для хранения:
- - заметок;
- - статуса важности;
- - статуса выполнения;
- - даты последнего изменения.
- Приложение должно быть реализовано по архитектуре MVVM:
- ViewModel управляет состоянием данных;
- UI подписывается на изменения через LiveData
- ViewModel не должна содержать ссылок на View или Context
- Настроить Dependency Injection: - Hilt
- Реализовать дополнительные функции:
- фильтрация заметок (например, важные / выполненные);
- сортировка заметок (по дате, по заголовку).

---

**5.0** – Продвинутые функции
*Функциональные требования*
- Реализовать напоминания о важных заметках:
- - с использованием AlarmManager или WorkManager (на выбор студента) + NotificationManager
- Уведомление должно приходить в заданное пользователем время.
- Реализовать возможность открытия конкретной заметки по нажатию на push-уведомление.
- Добавить голосовой ввод текста заметки (на выбор студента):
- - SpeechRecognizer API;
- - Google ML Kit (on-device);
- Допускается упрощённая реализация через ACTION_RECOGNIZE_SPEECH intent.
- Корректно обрабатывать разрешения:
- - доступ к микрофону;
- - уведомления.
